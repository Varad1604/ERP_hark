# SutraERP L5 — Historical Technical Material

This directory preserves technical material extracted from earlier architecture levels or historical implementation observations that is **not canonical current L5 production architecture**.

Current preserved artifacts:

- `L5-00_Technology_Stack_Baseline.md` — extracted from earlier L0 technology content under INT-002;
- `L5-01_Infrastructure_Persistence_Baseline.md` — extracted from earlier L2 persistence content under INT-008.

These files:

- are not part of the frozen 105-specification L5 production corpus;
- do not override current L5 governance, ADR decisions or approved specifications;
- do not automatically approve any technology, persistence pattern or implementation choice;
- remain preserved for provenance and feasibility context;
- require revalidation under current L5 governance before any architectural decision is adopted from them.

Canonical production L5 specifications belong under `../specifications/`.
Canonical L5 governance belongs under `../governance/`.
Canonical ADR documents will belong under `../adr/` when formally allocated.
